# CardPointe program fees for Odoo 19

Install this optional addon for a merchant enrolled in the CardPointe card program. On the **Card** payment method, open **Payment fees**, select the merchant’s CardPointe provider, and check **Use CardPointe surcharge**. Selecting it clears the manual rate on that row. Other methods and providers keep their own settings.

Checkout requests the fee from the gateway, shows the quoted total, and asks the payer to confirm. The gateway applies the fee to the original amount. Odoo records the gateway reference and receipt. A waived fee stays zero.
